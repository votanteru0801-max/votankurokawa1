# 命式相性ナビ（Webダッシュボード版）

算命学・四柱推命の命式（干支・五行・十大主星・十二大従星・空亡）に基づき、
メンバーの命式一覧・業務適性ランキング・今月の空亡メンバーをブラウザで確認できるツールです。

LINE連携は行わず、Webページ表示のみのシンプルな構成です。

## 表示内容

- 今月、空亡の時期にあたるメンバー一覧
- 全メンバー一覧（命式・日主・命式上の強み）
- 6領域（技術教育・採用・集客・SNS発信・組織構築・売上）ごとの適性ランキング

## ローカルでの動作確認

```bash
npm install
npm start
```

`http://localhost:3000/` にアクセスするとダッシュボードが表示されます。

## Renderへのデプロイ

1. このフォルダ一式をGitHubリポジトリにpush
2. Renderで「New Web Service」→ 対象リポジトリを選択
3. Environment（Runtime）は **Node** を選択（DockerfileでもOKですが、LINE連携が無くなったのでシンプルにNode Runtimeで問題ありません）
4. Build Command: `npm install` / Start Command: `npm start`
5. デプロイ完了後に発行されるURL（例：`https://xxxx.onrender.com/`）にアクセス

## メンバーデータの更新

`members.json` を直接編集し、GitHubに再pushしてください（Renderは自動で再デプロイします）。

## 精度に関する注意

- 干支の算出は標準的な暦計算に基づいています
- 月柱の節入り日は簡易計算（概算の節入り日を使用）のため、実際とは前後1日程度ずれる場合があります
- 業務適性・相性はすべて命式に基づく参考情報であり、人事評価や配置の断定的な根拠として使用しないでください
