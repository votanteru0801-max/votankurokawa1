# 命式相性ナビ（Webサイト版）

算命学・陰陽五行の命式（干支・五行・十大主星・十二大従星・空亡・大運、時間が分かれば時柱も）に基づく、
美容室スタッフの詳細分析・相性・チーム編成・採用候補者チェックツールです。

## できること

- 個人の詳細分析：検索ボックスに氏名を入力
- 相性チェック：メンバーを2名、セレクトボックスから選択
- チーム編成：テーマを入力すると5名を自動提案
  - 例：「石橋と相性のいい人」→ その人と相性の良いメンバーを提案
  - 例：「新しい技術のメニュー開発」→ 技術教育に適性のあるメンバーを提案
  - 「◯◯以上で」で役職による絞り込みも可能（役職データが入っている場合）
- 採用候補者チェック：氏名・生年月日（＋時間・想定役職）で分析
- アラート：今月空亡かつ大運が死・墓・絶のメンバー一覧
- 店舗別メンバー一覧

## ローカルでの動作確認

```bash
npm install
npm start
```

## メンバーデータの更新

`members.json` を直接編集し、GitHubに再pushしてください。
役職（role）を入れると、「◯◯以上で」によるチーム編成の絞り込みが使えるようになります。

## 精度・利用上の注意

適性・相性・アラートはすべて命式に基づく参考情報です。人事評価・採用可否・配置の断定的な根拠として使用せず、対話や見極めのきっかけとしてご活用ください。
