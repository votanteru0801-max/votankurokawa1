# 命式相性ナビ（Webサイト版）

算命学・四柱推命の命式（干支・五行・十大主星・十二大従星・空亡・大運）に基づき、
メンバーの詳細分析・相性・チーム編成・採用向け領域検索をブラウザで確認できるツールです。

## できること

- 検索ボックスから：
  - 個人の詳細分析（`山田太郎` / `山田太郎 今年`）
  - 相性診断（`山田太郎 佐藤花子`）
  - チーム編成分析（3名以上をスペース区切り）
  - 相乗効果検索（`山田太郎 相乗効果`）
  - 採用など領域検索（`採用` `集客` `SNS発信` `組織構築` `売上` `技術教育`）
- 今月、空亡の時期にあたるメンバーのアラート一覧
- 全メンバー一覧（命式・日主・命式上の強み）
- 6領域ごとの適性ランキング

## ローカルでの動作確認

```bash
npm install
npm start
```

`http://localhost:3000/` にアクセス。

## メンバーデータの更新

`members.json` を直接編集し、GitHubに再pushしてください。

## 精度・利用上の注意

- 干支の算出は標準的な暦計算に基づいています
- 業務適性・相乗効果・アラートはすべて命式に基づく参考情報です。人事評価や配置の断定的な根拠として使用せず、対話のきっかけとしてご活用ください
