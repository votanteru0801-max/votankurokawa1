# 命式相性ナビ（Webサイト版）

算命学・陰陽五行の命式（干支・五行・十大主星・十二大従星・空亡・大運、時間が分かれば時柱も）に基づき、
美容室スタッフの詳細分析・相性・チーム編成・採用候補者チェックをブラウザで確認できるツールです。

## できること

- 検索ボックスから：個人の詳細分析／相性診断（2名）／チーム編成分析（3名以上）／相乗効果検索
- 採用候補者チェック：氏名・生年月日（＋分かれば生まれた時間・想定役職）を入れて分析
- 今月、空亡の時期にあたるメンバーのアラート一覧
- 店舗別メンバー一覧

## 表現方針

- 算命学・陰陽五行の用語（十大主星・十二大従星）のみで説明し、四柱推命の別名併記はしていません
- 美容師・アイリスト・ネイリストなど現場でイメージしやすい言葉で表現しています
- 役職を入力すると、その役職での強みも表示されます

## ローカルでの動作確認

```bash
npm install
npm start
```

`http://localhost:3000/` にアクセス。

## メンバーデータの更新

`members.json` を直接編集し、GitHubに再pushしてください。性別（gender）を設定すると大運も算出されます。

## 精度・利用上の注意

- 干支の算出は標準的な暦計算に基づいています
- 時柱は生まれた時間の情報がある場合のみ算出されます（不明な場合は表示されません）
- 適性・相乗効果・アラートはすべて命式に基づく参考情報です。人事評価・採用可否・配置の断定的な根拠として使用せず、対話や見極めのきっかけとしてご活用ください
